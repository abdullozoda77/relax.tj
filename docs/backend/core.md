# `core/` — Django project package

`core` is the project created by `django-admin startproject core`. It holds configuration only; all business code
lives in the apps (`accounts`, `places`, `assistant`).

| File | Purpose |
|---|---|
| `__init__.py` | Imports the Celery app (`from .celery import app as celery_app`) so `@shared_task` functions bind to it when Django starts |
| `settings.py` | All settings, read from `.env` |
| `urls.py` | Root URL configuration + Swagger/ReDoc |
| `celery.py` | Celery application |
| `wsgi.py` | WSGI entry (`core.wsgi:application`) — used by gunicorn in production |
| `asgi.py` | ASGI entry (not used in production; generated by Django) |

Also at the repository root: `manage.py` (sets `DJANGO_SETTINGS_MODULE=core.settings` and runs commands).

## `settings.py` — section by section

### Environment
- `load_dotenv(BASE_DIR / '.env')` — loads variables from `.env`.
- `SECRET_KEY` (default `django-insecure-change-me`), `DEBUG` (`'True'` string → bool),
  `ALLOWED_HOSTS` (comma-separated).

### Installed apps
Django contrib apps + `corsheaders`, `rest_framework`, `rest_framework_simplejwt.token_blacklist`
(stores blacklisted refresh tokens), `django_filters`, `drf_yasg`, and the project apps `accounts`, `places`,
`assistant`.

`AUTH_USER_MODEL = 'accounts.User'` — the custom user model.

### `REST_FRAMEWORK`
| Key | Value | Meaning |
|---|---|---|
| `DEFAULT_AUTHENTICATION_CLASSES` | `JWTAuthentication` | `Authorization: Bearer <access>` |
| `DEFAULT_PERMISSION_CLASSES` | `IsAuthenticatedOrReadOnly` | Reads are public, writes need login (views override this) |
| `DEFAULT_FILTER_BACKENDS` | `DjangoFilterBackend`, `SearchFilter`, `OrderingFilter` | `?field=`, `?search=`, `?ordering=` on every list |
| `DEFAULT_PAGINATION_CLASS` | `places.pagination.StandardPagination` | Page number pagination |
| `PAGE_SIZE` | 10 | |
| `DEFAULT_THROTTLE_CLASSES` | `AnonRateThrottle`, `UserRateThrottle` | |
| `DEFAULT_THROTTLE_RATES` | anon `1000/hour`, user `5000/hour`, `auth` `10/minute`, `assistant` `15/minute` | `auth`/`assistant` are scoped (`ScopedRateThrottle`) |

### `SIMPLE_JWT`
Access token 60 minutes, refresh token 7 days, `ROTATE_REFRESH_TOKENS=True` (each refresh returns a new refresh
token) and `BLACKLIST_AFTER_ROTATION=True` (the old one stops working). Header type `Bearer`.

### `SWAGGER_SETTINGS`
Adds a "Bearer" API-key security definition so you can paste a token in Swagger UI; session auth disabled.

### Middleware
`SecurityMiddleware → CorsMiddleware → Session → Common → Csrf → Authentication → Messages → XFrameOptions`.
`CorsMiddleware` must be high in the list so it can add headers to every response.

### CORS / CSRF / HTTPS
- `CORS_ALLOWED_ORIGINS` — from `.env` (defaults: `http://localhost:3000,http://localhost:5173`).
- `CSRF_TRUSTED_ORIGINS` — needed for the Django admin login behind nginx.
- If `HTTPS=True`: `SECURE_PROXY_SSL_HEADER = ('HTTP_X_FORWARDED_PROTO', 'https')`, secure session and CSRF cookies.

### Database
SQLite at `BASE_DIR / 'db.sqlite3'`.

### Internationalisation
`LANGUAGE_CODE='ru'`, `TIME_ZONE='Asia/Dushanbe'`, `USE_I18N=True`, `USE_TZ=True`.

### Static and media
`STATIC_URL='/static/'`, `STATIC_ROOT=BASE_DIR/'static'` (filled by `collectstatic`, served by nginx);
`MEDIA_URL='/media/'`, `MEDIA_ROOT=BASE_DIR/'media'` (uploads + thumbnails).

### Email (`MAILERS`, Django 6.1 style)
If `EMAIL_HOST`, `EMAIL_HOST_USER` and `EMAIL_HOST_PASSWORD` are all set → SMTP backend with host/port/user/password/
TLS/SSL and 15 s timeout. Otherwise → console backend (letters are printed). Note: the local variable is named
`smtp_host` (lower case) because Django 6.1 refuses old `EMAIL_*` settings next to `MAILERS`.
`DEFAULT_FROM_EMAIL` = `"Rohat" <EMAIL_HOST_USER or noreply@rohat.tj>`.

### AI assistant
`GEMINI_API_KEY`, `GEMINI_MODEL` (default `gemini-3.8-flash`), `GEMINI_FALLBACK_MODELS`
(default `gemini-3.7-flash,gemini-3.6-flash`), `ANTHROPIC_API_KEY`, `ASSISTANT_MODEL` (default `claude-opus-5`),
`ASSISTANT_EFFORT` (default `low`).

### Celery
- `CELERY_BROKER_URL` — e.g. `redis://127.0.0.1:6379/12`.
- `CELERY_TASK_ALWAYS_EAGER = not CELERY_BROKER_URL` — **no broker → tasks run immediately in the request**.
- `CELERY_TASK_EAGER_PROPAGATES=True`, `CELERY_TASK_IGNORE_RESULT=True`,
  `CELERY_BROKER_CONNECTION_RETRY_ON_STARTUP=True`, `CELERY_TIMEZONE='Asia/Dushanbe'`.
- `CELERY_BEAT_SCHEDULE` — `nightly-cleanup` runs `accounts.tasks.cleanup` every day at **03:30**.

### Other
`FRONTEND_URL` — base URL used in password reset emails (default `http://localhost:5173`).

## `urls.py`

```python
schema_view = get_schema_view(openapi.Info(title="Rohat API", default_version='v1', ...), public=True,
                              permission_classes=(AllowAny,))
urlpatterns = [
    path('admin/', admin.site.urls),
    path('api/auth/', include('accounts.urls')),
    path('api/assistant/', include('assistant.urls')),
    path('api/', include('places.urls')),
    re_path(r'^swagger/$', schema_view.with_ui('swagger', cache_timeout=0)),
    re_path(r'^redoc/$',   schema_view.with_ui('redoc',   cache_timeout=0)),
] + static(settings.MEDIA_URL, document_root=settings.MEDIA_ROOT)
```

The Django admin is branded: `site_header = site_title = "Rohat"`, `index_title = "Панель управления"`.

## `celery.py`

```python
os.environ.setdefault("DJANGO_SETTINGS_MODULE", "core.settings")
app = Celery("rohat")
app.config_from_object("django.conf:settings", namespace="CELERY")  # reads CELERY_* settings
app.autodiscover_tasks()                                             # finds accounts/tasks.py
```

Run: `celery -A core worker` and `celery -A core beat` (see [../deploy.md](../deploy.md)).

## Environment variables (`.env`)

| Variable | Default | Used for |
|---|---|---|
| `SECRET_KEY` | insecure dev key | Django crypto signing |
| `DEBUG` | `True` | Debug mode |
| `ALLOWED_HOSTS` | `127.0.0.1,localhost` | Allowed Host headers |
| `CORS_ALLOWED_ORIGINS` | `http://localhost:3000,http://localhost:5173` | Frontend origins |
| `CSRF_TRUSTED_ORIGINS` | empty | Admin login behind a proxy |
| `HTTPS` | `False` | Trust `X-Forwarded-Proto`, secure cookies |
| `FRONTEND_URL` | `http://localhost:5173` | Links in emails |
| `EMAIL_HOST`, `EMAIL_PORT`, `EMAIL_USE_TLS`, `EMAIL_USE_SSL`, `EMAIL_HOST_USER`, `EMAIL_HOST_PASSWORD` | empty / 587 / True / False | SMTP |
| `DEFAULT_FROM_EMAIL` | `"Rohat" <user>` | Sender |
| `GEMINI_API_KEY`, `GEMINI_MODEL`, `GEMINI_FALLBACK_MODELS` | see above | AI (Gemini) |
| `ANTHROPIC_API_KEY`, `ASSISTANT_MODEL`, `ASSISTANT_EFFORT` | see above | AI (Claude) |
| `GOOGLE_CLIENT_ID` | empty | Continue with Google (OAuth client ID, Web application); empty hides the button |
| `CELERY_BROKER_URL` | empty | Redis broker; empty = run tasks inline |
